# Agent Liquidity Copilot

> Built for **AI Dev Fest 2026** (DIU-CPC × upay) | Track 05: Merchant & Agent Intelligence

## Overview

MFS agents often run out of cash or e-float at peak hours. Each stockout means lost cash-out transactions and unhappy customers.

**Agent Liquidity Copilot** is an AI assistant that:
1. Forecasts hourly cash-out demand for an agent.
2. Compares the forecast with the agent's current cash and float.
3. Recommends when and how much to rebalance, before a stockout happens.
4. Explains each recommendation in plain language.

**Problem statement:** For MFS agents in semi-urban and rural areas, running out of cash or e-float at peak hours causes lost cash-out transactions and unhappy customers. We built an agent liquidity copilot that uses synthetic transaction history to forecast hourly cash-out demand and recommend when and how much to rebalance, with success measured by the reduction in simulated stockout events versus a naive baseline.

**Data privacy:** This project uses only synthetic data generated by our own script. No real customer or agent data (PII) is used anywhere.

## Features

- Synthetic data generator with realistic patterns (peak hours, weekdays vs. weekends, salary-cycle days, festival spikes)
- Baseline forecast ("same hour last week") and a LightGBM forecasting model
- Business-rules layer, kept separate from the ML model, that turns forecasts into rebalance recommendations
- Stockout simulation that compares baseline vs. AI-driven recommendations
- Interactive Streamlit dashboard: demand forecast, risk hours, recommended actions
- Plain-language explanations of each recommendation (English, with Bangla planned)
- Human oversight: the agent approves or rejects every recommendation; nothing is automatic

## Setup / Run

**Requirements:** Python 3.9 or newer, and Git.

```bash
# 1. Clone the repository
git clone https://github.com/tareq-x/agent-liquidity-copilot.git
cd agent-liquidity-copilot

# 2. Create and activate a virtual environment
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt
```

## Environment Variables

Currently none are required to run the core project.

If the optional LLM explanation feature is enabled, create a `.env` file in the project root (it is already git-ignored):

```
LLM_API_KEY=your_key_here
```

Without a key, the app falls back to template-based explanations.

## Responsible AI Notes

- **Explainable:** every recommendation shows the forecast and the rule that triggered it.
- **Human in the loop:** agents approve each action before it is taken.
- **Private:** synthetic data only.
- **Separation of concerns:** the ML model predicts demand; transparent business rules decide actions. Decision logic is not hidden inside an LLM prompt.
